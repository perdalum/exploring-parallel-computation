## [0.1.0] - 2026-09-06

### Added

- Sequential and parallel computation examples in C++, Swift, Node.js JavaScript, Julia, Python, and Wolfram Language.
- A compiled Wolfram Language variant using `FunctionCompile`.
- Make targets for building the C++ and Swift programs and running the main demonstrations.
- A Wolfram notebook for interactive exploration.
- The article “Explorations into parallel computing” and its accompanying image.
- Ignore rules for locally compiled binaries and macOS metadata.
- Project documentation and an MIT license for the source code.
